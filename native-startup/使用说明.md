# Codex 爱弥斯启动入口

入口：`${HOME}/Applications/Codex 爱弥斯.app`，桌面有同名快捷入口。

1. 保存正在进行的工作，等当前任务结束。
2. 用 ⌘Q 完全退出当前 Codex / ChatGPT 应用。
3. 双击桌面「Codex 爱弥斯」。真实 Codex 窗口打开后，在同一个窗口内播放旋转碎线、角色轮廓归位、显色动画；按 Esc 可跳过。
4. 动画结束后检查主界面的爱弥斯背景；切换任务再检查背景是否保留。

壁纸桥接仅连接本机 127.0.0.1:19327，且仅允许 app://-/index.html 主界面。该调试端口使本机进程能够访问应用调试功能；仅使用可信本机软件。桥接没有读取或上传聊天内容。原应用文件、签名、登录数据均未修改。

如果 Codex 不是从爱弥斯入口冷启动，可能没有本机调试接口；这时需要完整退出一次，再从新入口打开。已由爱弥斯入口启动后，可重复调用 URL 接口在同一窗口重播动画。

恢复：完全退出 Codex，直接打开原来的桌面 ChatGPT.app。关闭后注入样式消失，桥接在接口消失后约两分钟自行退出。需要卸载时删除 Applications 下的「Codex 爱弥斯.app」和桌面同名快捷入口即可。

日志：~/Library/Logs/AemeathStartup/events.log 与 wallpaper.log。

已验证：Swift 编译、资源定位、JS 语法；2026-09-19 14:33 从入口冷启动，实际 Codex PID 8793 带调试参数启动，动画首帧、线条、显色和正常退出均有运行记录；14:35 主界面截图确认壁纸显示、正文可读。截图为 native-startup/live-main.jpg。
壁纸桥接持续运行，每三秒检查主界面。已排除桌宠及浏览器页面。应用未来更新后可能需要调整样式。
