# 爱弥斯启动接口

## macOS URL

`codex-aemeath://launch`

从快捷指令、桌宠或其他应用打开此地址，即打开真实 Codex，在 Codex 自身窗口内播放启动动画与已缓存语音，并接入皮肤。

终端调用：

```sh
open 'codex-aemeath://launch'
```

## 命令行入口

```sh
'${HOME}/Documents/ChatGPT/桌宠+codex皮肤/native-startup/bin/codex-aemeath'
```

可选 `--preview` 只播放动画，`--self-check` 检查应用和媒体路径。

当前版本语音在 1.1 秒触发，从安装包读取 WAV，不调用 Pinokio。启动总时长约 12 秒，Esc 可跳过。动画是 Codex 页面内部的全窗口图层，不再创建另一个启动窗口，因此动画、背景和正式界面的尺寸与位置完全一致。

接口仅为本机 URL 协议及命令行入口，没有新开 HTTP 控制端口。

## 皮肤

主题源文件为 `theme.css`。已安装副本位于 `~/Applications/Codex 爱弥斯.app/Contents/Resources/theme.css`。由 wallpaper-bridge.mjs 在下次启动时加载。主题作用于 Codex 主界面，保留原图颜色，使用中性深灰和白色文字；输入框与历史侧栏为半透明模糊玻璃。

恢复默认：完全退出 Codex 后，从原来的 ChatGPT.app 启动。
