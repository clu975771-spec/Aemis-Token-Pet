# Codex Token 小气泡

一个独立的 macOS 悬浮窗：每 4 秒读取本机 Codex 记录，显示最近操作项目中所有对话的累计 Token，以及最新一轮对话的 Token。

双击 `启动 Token 小气泡.command` 即可运行。首次启动时 macOS 可能需要你确认打开该文件。

它只读取 `~/.codex/state_5.sqlite` 与 `~/.codex/sessions` 下的本地记录，不调用网络或 API。气泡会显示最近聚焦项目的总消耗；可直接拖动，菜单栏的 `◌ Token` 可手动刷新或退出。

点击下方人物会立刻刷新数据，并触发一次短促的果冻按压和两下音效：人物和聊天气泡一起轻微变形后回正，不会连续上下弹跳。右键人物可选「低沉咚咚 / 清脆啵啵 / 活泼噗噗」，通过滑杆自由调整音量，或直接关闭音效；它们都使用 macOS 自带资源，不需下载素材。

如果在 3 秒内连续点击人物 15 次，气泡会显示「不要再拍我了」5 秒，随后自动回到原来的内容。

右键点击人物可打开「爱弥斯 · 角色工作台」。它有默认预设，并可将当前人物图、聊天框颜色、连点台词、音效、音量和两个尺寸保存为新预设，一键切换。人物与聊天框大小均可用连续滑杆自定义，悬浮窗会同步改变尺寸以避免裁切。聊天框颜色只有按「确定」才会应用；「取消」会保持原样。

音效提供低沉咚咚、清脆啵啵、活泼噗噗、轻吹呼呼、玻璃叮咚、小青蛙、猫咪呼噜、潜水雷达共 8 种，也支持导入不超过 15 秒的音频。连续点击 15 次时会展示自定义台词和连点速度（次/秒）5 秒；右键菜单可记住当前悬浮窗位置。

## 爱弥斯互动素材

在「爱弥斯 · 角色工作台 → 互动素材与触发条件」中，可以分别批量导入触发图片、点击语音、触发语音。图片支持系统可读的常见格式（如 PNG、JPG、WebP、GIF）；音频支持系统可读的常见格式且每段不超过 15 秒。触发条件有：连续点击 2 次、5 次、15 次、15 秒未互动、切换前台软件。每种条件可绑定多份图片与语音，爱弥斯会随机挑选；点击语音则独立随机播放。

导出的 `.aemispreset` 会一并打包人物、互动图片和两类语音，可在其他设备上导入分享。

说明：原生 Codex 宠物的格式只包含精灵图和基本元数据，因此动态数字由这个独立气泡显示，而不是写入宠物动画图片中。人物素材已做透明抠图并用于这个独立组件。
